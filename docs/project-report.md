## 2. 环节一：M0 导航线（BC → DAgger 完整链路）

### 2.1 环境

- **约束**: 纯 CPU（`CUDA_VISIBLE_DEVICES=`），不占 GPU（27B 对话占着）

### 2.2 BC 数据收集（`collect_bc.py`）
- Teacher（余弦弧线）在 sim 里跑 10s/episode，270k 对 (obs, act)
- obs 8-d：目标 body 系 x/y + heading sin/cos + 线速度 vx/vy + 左右轮速
- act 2-d：左右轮力矩 [-1, 1]

### 2.3 BC 训练（`train_bc.py`）
- 模型：MLP 8→64→64→2，tanh 激活，MSE loss，Adam
- **结果**:
  - sim 成功率 **~69–72%**
  - arena 成功率 **60%**
  - **结论**: BC 基线可复现，**追不上 teacher**（见 2.4 分析）

### 2.4 Teacher 行为分析（为什么 BC 追不上）
- Teacher 是 analytic（直接算公式），BC 是统计（学分布）
- Teacher 在 |ang|>90° 失效（`cos(ang)→0`），**BC 学到的分布里也包含这个失效模式**
- 所以 BC 的"最优"就是"学 teacher 的均值"，**不可能超 teacher**（除非有额外信息）
- → **需要 DAgger**（用 student 自己分布的失败样本，让 teacher 重新监督）

### 2.5 DAgger（`dagger.py`）
- **轮数**: 5 轮
- **每轮**: 8k → 16k → 24k → 30k → 30k 对（student rollout → teacher 补标 → 联合训练）
- **耗时**: 2.6 min/轮（纯 CPU）
- **结果**:
  - arena: **65% → 74% → 78–82%**（5 轮增益 4–12pt）
  - 训练域（gen_test N=500）: **82%**
  - **近目标（r<0.9m）: 97%**（这个距离 teacher 反而 85%）
  - **远超（r>2m）: ~50–55%**（teacher 同崩，52–54%）
- **结论**: DAgger **不超 teacher**（arc 58% vs teacher 63% vs DAgger r2 73%）
  但在**训练域内**稳超 BC，**近目标大幅领先**，远超时同崩（物理上限，真·到顶）

### 2.6 泛化 stress test（`gen_test.py`，N=500）
跨目标距离 5 档，测泛化：
| 距离档 | BC | DAgger | Teacher |
|---|---|---|---|
| 0.6–1.5 m（训练域） | 75% | **82%** | 75% |
| 0.3–0.9 m（近） | 85% | **97%** | 85% |
| 0.4–2.2 m（中） | 63% | 66% | 66% |
| 1.5–2.0 m（远） | 50% | 54% | 54% |
| 2.0+ m（远超） | ~45% | ~52% | 52% |

**关键洞察**:
- **训练域内**: DAgger > BC > Teacher（student 分布更贴）
- **远超时**: 三者同崩到 ~50% → **这是数据+控制器的物理上限**，不是算法问题

### 4.2 装配步骤（到货后）
1. **机械**: 底盘装 2 电机 + 万向轮（万向轮朝前），电池仓居中
2. **电气**: 
   - 4S 电池 PDB → 分出 5V（ESP32-S3）+ 12V（电机驱动）
   - 电机 A、B 相 → TB6612 的 AOUT1–2 / BOUT1–2
   - TB6612 的 IN/PWM → ESP32-S3 的 GPIO
   - IMU (MPU6050) → I2C (GPIO 4/5)
   - VL53L0X × 3 → I2C（同一总线，不同地址）
3. **软件**: ESP-IDF 框架，Arduino-ESP32 也行（v3.x 支持 S3）

### 4.3 策略上板（int8 量化）
1. **训练侧**: BC/DAgger 的 MLP (8→64→64→2) → **TFLite** 导出 → **int8 量化**（~2KB flash）
2. **ESP32-S3 侧**:
   - **TensorFlow Lite Micro** 跑 int8 推理（每次 < 1 ms）
   - 感知：IMU 融合（EKF/互补滤波）→ 估计底盘 heading + 线速度
   - 超声：VL53L0X × 3 → 相对目标距离
   - 目标点：遥操模式（手机/PC 发）或自主模式（超声阵列估计）
3. **控制**: 左右轮 PWM（ESP-IDF 的 `ledc` 模块，20 kHz）
4. **遥操**: 手机蓝牙/WiFi → ESP32-S3 → 目标点 → 策略 → 轮速
5. **自主**: 超声 + IMU → 同策略 → 自主到达目标
