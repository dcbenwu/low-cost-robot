# 真机 BOM（M2 基础版 · 修正版 v2）

> 目标：差速移动底盘 + 低成本感知 + ESP32-S3 主控，可被 Mac/udoge 远程遥操并部署 BC/DAgger 策略。
> 价格按 2026 淘宝常见区间估算，采购以实际链接价为准（本文件只锁型号与电压配套关系）。
>
> ### ⚠️ v2 修正点（对照 v1 的已知硬伤）
> 1. **电机电压与电池配对一致**：v1 是「24V 电机 + 4S 14.8V」，两者不匹配。v2 改为 **12V 660 编码器电机 + 3S 11.1V 2600mAh**（若上 24V 大功率，则驱动板一并换 BTS7960）。
> 2. **驱动板电流/电压上限写死**：TB6612FNG 连续 1.2A/通道、耐压 4.5–15.8V —— 恰好覆盖 3S 满电 12.6V，不超压。
> 3. **VL53L0X 有效距离改 ~2 m**（ datasheet 0.1–4 m 是理想值，实际可靠 ~2 m），并把 3 个传感器 **XSHUT 引脚改 I2C 地址**（默认全 0x29 会冲突）。
> 4. **术语统一为「ToF 激光测距」**（VL53L0X 是飞行时间激光，不是超声 HC-SR04）。
> 5. **自主定位降级为遥操/半自主**：M2 阶段目标点由手机 App / 信标（AprilTag 或 IR beacon）下发，不做「超声阵列估计目标」的那种全自主定位（缺定位方案不可行）；全自主建图导航列入 M3+ 并用真实定位（AprilTag+相机 或 廉价 LiDAR）。
> 6. **预算重算**：基础版 ≈ ¥700–1,400（v1 虚高到 ¥1,000–1,700）。

> ### 装配要点（对应上述修正）
> 1. 底盘装 2 个 12V 660 电机 + 万向轮（万向朝前），电池仓居中、尽量低。
> 2. 电池 3S PDB → 出 5 V（ESP32-S3）+ 12 V（驱动板）两路；电机 A/B 相 → TB6612FNG 的 AOUT1/2 / BOUT1/2；TB6612 IN/PG/PWM → ESP32-S3 GPIO。
> 3. 三个 VL53L0X：每片 XSHUT 接 ESP32-S3 一个独立 GPIO，通过高/低电平（或外部分压）切 I2C 地址 0x29 / 0x52，避免同址冲突；或分挂不同 I2C 总线。
> 4. MPU6050 → ESP32-S3 I2C (GPIO 4/5)。
> 5. 编码器 A/B 相 → ESP32-S3 硬件定时器捕获（或经计数模块），用于里程计 + 速度闭环。
> 6. 遥操链路：手机 App / PC 脚本 → UDP/TCP (5.8 GHz 2.4 GHz WiFi) → ESP32-S3 → obs → MLP 推理 → 两轮 PWM (esp-ledc @ 20 kHz)。
